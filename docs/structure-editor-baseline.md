# 结构编辑器稳定基线

结构绘制能力从本基线起冻结。后续工作默认进入动画编辑主线；除非自动化测试或实际工程证明发生回归，不再增加结构工具，也不调整键、环、标签、楔键或描绘样式。

## 写入边界

- 基础结构只能在当前选中、启用且目标分子仍有效的 `molecule_create` 节点上下文中修改。
- 选择结构工具不会清空节点选择；离开有效创建节点后，所有结构写工具立即禁用。
- 原子/键/标记修改、删除、橡皮擦、快捷键和画布手势都在 C++ Core 命令边界再次检查上下文，不能依赖 Python 界面兜底。
- `TimelinePreview`、播放和最终效果预览均为只读；其中不允许结构写入，也不允许误用结构撤销栈。

## 动画编辑边界

- 线性节点是创作层，typed tracks 是 Core 根据节点顺序编译出的求值结果。
- 选中支持直接操作的 Set/Lerp 节点后，画布拖动只更新该节点参数，不写回基础 atom/bond/XY。
- 拖帧或播放进入只读预览；停止播放或重新选择节点后，界面标签、工具可用状态和 Core `EditTargetKind` 从同一个状态恢复。
- Wait 决定后续节点起始帧；不同属性可以并行，同一属性的后发插值从接管帧当前值继续。

## 回归门槛

`tests/test_native2d.py` 和 `tests/test_editor_ui.py` 覆盖无效上下文写入、删除/手势/撤销隔离、节点选择保留、播放与拖帧状态、Set/Lerp 直接操作、Wait/排序/重叠插值、撤销重做、保存重开、Lua 同源以及 `mod/visual_events` 的前后向求值。

如需修改冻结区域，应先提交能复现问题的回归测试，并保持编辑器预览、生成 Lua 和 C++ 最终渲染的逐帧语义一致。
